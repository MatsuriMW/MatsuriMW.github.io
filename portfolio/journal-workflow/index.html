FLOW · 一天怎么转

一天是怎么转起来的

从早上写下计划、多 Agent 并发派活，到晚上对账复盘，都在同一篇日记里。

01晨间排程

写下计划，螺旋自动填进空档

  • 自然写日程：固定事件写时刻（支持中文时段、AM/PM 与跨夜「次日」解析），待办写预计时长，每分钟自动重排进空档。
  • 作息预设与自动扩展：点击顶栏日夜菜单切换或自定义作息预设，更早或更晚的记录自动撑开螺旋边界。
  • 主线与外沿番茄钟：模糊简写（如 todo a）自动转成 A/B/C 彩色徽标；右键任务色块直接开 15m/25m/自定义外沿番茄钟。
02派活与编排

任意段落直派，多 Agent 分批接力

  • 无摩擦派发：光标跟随纸飞机、列表拖拽、@agent/模型/强度与右键菜单都能直接派活，并支持先出派发草稿与载荷快照。
  • 多批工作台：内置 5 套小队，支持第 1/2/3 批依赖接力、同批文件重叠预警与一键错峰，全程由管家 Agent 巡检汇总。
  • 原地分形看板：父块一键切换二维看板（按状态 / 子组）并支持跨笔记镜像卡，ContextBundle 内核确保隐私闸门与零静默截断。
03甲板总览

一张甲板看清 21+ Agent 与 11 家终端

  • 全生态追踪：自动探测并收拢 21 家内置 Agent（含 Claude Code、Codex、Antigravity、Cursor、Trae、Orca、Cindy、Kimi、DSH 等）与自定义 ACP。
  • 原生标题与零依赖读取：跨客户端统一同步本地重命名，基于内置 node:sqlite 只读解析本地库，macOS 与 Windows 均免装 sqlite3。
  • 螺旋内圈与常驻浮窗：螺旋内圈以颜色区分各 Agent 并发时段；配套 macOS 菜单栏面板（支持一键置顶 Pin）与 11 家终端直达。
04回写与整理

结论落回日记，像大纲一样顺手整理

  • 不扰排程的回写：默认采用子块 - ⏱ 计时保留母块预估时长，行内进度（25%、1/3）无损承接；Agent 提问进 ❓/✍️ 回复信箱原地续聊。
  • 顺手整理记录：拖拽会话默认挂为缩进子块，⌘⌥↓ 一键合并成组，右键可 Pin 关键轮次（折叠不隐藏），⌃⌥L 自动分区排布。
  • 一处记录四种视角：同一条 AI 记录可原地切换大纲 / 表格 / 卡片 / 时间线并导出，多会话联合任务自动汇总去重时长与 Token。
05记忆图谱与 MCP

一文一条记忆库，外供 9 家客户端

  • 可审阅的记忆库：Dreaming 从近 14 天记录提炼一文一条 Markdown 记忆，附双向原文回链，支持 Base 表格、三列看板与冲突裁决。
  • 双主题记忆图谱：独立记忆图谱视图提供「编辑室 / 星图」两套主题、防重叠胶囊标签与语义分岛，随时按核验状态筛选跳回原笔记。
  • 外部客户端一键接入：通过零依赖 memory-query CLI 与 stdio memory-mcp + SQLite FTS5，一键接入 9 家外部客户端，严格屏蔽私密笔记与 AI 日志。
06晚间复盘与洞察

六维复盘、热力图与离线安全审计

  • 六维当日复盘：对照每项任务的预计时长与番茄钟多段实际用时，配合近 30 天预估校准曲线，未记录时段以斜纹标出。
  • 协作回顾 Dashboard：展示每日 Token 热力图、24 小时并发作息、模型分布与项目投入排行，一键下钻回来源日记块。
  • 离线安全回放：一键回放近 7/30 天工具调用生成脱敏审计报告，在 frontmatter 维护白名单并同步到实时 ACP 权限护栏。

WHY PLAIN MARKDOWN

一份大纲，零黑盒锁定

唯一正本

人的计划、分形看板、AI 每轮记录、派发快照与长期记忆，全部是库里的普通 Markdown 文件。

无损投影

Base 表格、四视图、分形看板、记忆图谱与 Dashboard 都是文本投影——删掉视图不丢数据，改字立刻生效。

结构优先于黑盒 RAG

人工写就的大纲层级、[[双链]]、#^块号与 private: true 隐私闸门，比黑盒向量检索信噪比更高、每条都可溯源。
