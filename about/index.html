About

¶关于我

赛博名字是马自立，26 岁男性，在无锡长大。
当过三年英语老师，兼做教育机构的产品运营，后来在一家做医疗器械渠道系统的公司当过产品助理。现在主要在做 AI 应用：用 Claude Code 写 Obsidian 插件、Agent 工作流和 Skill，代码都放在 GitHub 上。
兴趣广泛而杂食，曾经是个二次元，自学过一阵语言学。
INTJ-T，长期使用 macOS 和 Obsidian，笔记记了四年，大半个人生活都在这个库里。
《黑暗之魂》系列骨灰玩家。英语六级 587，能当工作语言；日语 N3 持证，勉强能读。

¶在做什么

做过的项目都在下面，🔗 是 GitHub 仓库，Demo 🔗 是在线演示（汇总页在「GitHub 项目」）。一共写了三十来个 Obsidian 插件，其中 5 个上架了官方社区插件市场。

  • 第二大脑：把我笔记库里公开的部分放到线上，可以直接对它提问，回答带出处，检索每一步的分数都摊开了。🔗 · Demo 🔗
  • Agent Deck（智能体甲板）：Obsidian 插件，把散在各个客户端里的 AI Agent 会话收到一张甲板上，活从笔记里派出去，进度和结果回到笔记里。已上架。🔗 · Demo 🔗
  • 螺旋日程：Obsidian 插件，把一天的事件和待办画成一圈螺旋，待办自动填进空档。已上架。🔗 · Demo 🔗
  • 小红书舆情研判：定时跑的舆情工作流，模型逐条编码、代码算指标、规则和另一个模型打分，最后人工复核。🔗 · Demo 🔗
  • Token 小票：Obsidian 插件，把一天用掉的 AI token 打成一张购物小票，按 API 标价折算金额。已上架。🔗
  • Telegram Companion：Obsidian 插件，手机上随手发一句进当天日记；想聊的时候，它先读你近一周的日记再开口。已上架。🔗
  • Roam Backlinks：Obsidian 插件，像 Logseq、Roam Research 那样在反链里逐块原地编辑。已上架。🔗
  • AI 人物设计 Skill：把模糊的人物感觉拆成生图、生视频模型能直接执行的描述，附 122 张人物原型卡。🔗
  • 角色设定板 + 古典式配图：两个 Claude Skill，一个锁定角色长相，一个画版画质感的解释图。🔗
  • Obsidian-Plugins：我自用的全部 Obsidian 插件，按推荐度标好了。🔗
  • skills-agents-and-prompts：写稿流水线、带出处的笔记问答、投资调研 Agent 等 Skill 和提示词。🔗
