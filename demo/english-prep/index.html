英语备课 Agent

给无锡初中英语老师用的备课助手。一份教案同时贴合四样东西：年级（下一场考试考什么）、学校（这场考试用谁的卷子）、学生（薄弱点）、老师（讲题习惯和这次的要求）。老师和学生的档案是会自己更新的记忆：课后随手记一笔，agent 把它拆成增删改，每条都能撤销；课记得越多，它给的教案改进建议越具体。教案不一步到位：先出大纲，老师改环节、分钟、用题，确认后再写成教案；写好以后在「审教」页过一遍，要改的地方跟 agent 商量着改。每节课还会自动加一段课外知识补充：按这节课用到的题，挑词根词缀、熟词僻义、真考过的俗语谚语这类现成讲解。

学生是虚构的，学校是真实学校。没登录时，改动只存在这个浏览器里；登录后存进账号，换台电脑接着用。

备课流程

五步按顺序走：看档案 → 定下一场考试 → 调四个维度的占比、排大纲 → 写成教案 → 审教校验（自动检查 + 老师自己看，要改的跟 agent 说）。哪一步都能回头改，改动自动保存（登录了就存进账号）。
