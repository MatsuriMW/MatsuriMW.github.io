螺旋日程（Nautilus Spiral）

给每一分钟安排一份工作。螺旋日程读今天的日记，把事件和待办画成一圈螺旋：固定事件钉在它的时刻上，待办按列表顺序和预计时长，从「现在」开始自动填进事件之间的空档。时间往前走，没做完的任务就跟着往后流；排不下的，当场告诉你缺多少。日历里的日程、Agent 会话的进度和用时，也都落在同一圈上。

50 秒，有音效，没有旁白。片子里的面板是插件自己的代码按一篇虚构日记逐帧画出来的，不是录屏。

GitHub 仓库 配套插件 Agent Deck 的演示 马自立的其他项目

螺旋日程是 Obsidian 插件，MIT 开源，仅桌面端。
